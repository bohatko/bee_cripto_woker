# МАТЕМАТИЧЕСКАЯ СТРАТЕГИЯ И ОТЧЕТ ПО БЭКТЕСТАМ
## Проект: Bee Crypto Worker (Стратегия Мульти-Парной Корзины)

---

## 1. Теоретическая база стратегии (Market-Neutral Alpha)

Большинство розничных трейдеров теряют депозиты, пытаясь угадать направление движения Биткоина (Long или Short). На крипторынке движения BTC хаотичны, зависят от геополитики, решений ФРС, речей чиновников и манипуляций маркет-мейкеров со сбором ликвидаций.

**Рыночно-нейтральный парный трейдинг (Pairs Trading / Synthetic Cross)** полностью устраняет рыночный риск (Market Beta = 0):
* Вместо ставки на то, вырастет ли монета к доллару (USDT), мы торгуем **соотношением двух монет (Ratio)**:
  $$\text{Ratio} = \frac{\text{Price}_{\text{Coin A}}}{\text{Price}_{\text{Coin B}}}$$
* Одновременно открываются две противоположные позиции на равный долларовый объем:
  * **LONG Coin A** (сильный актив) на $X.
  * **SHORT Coin B** (слабый актив) на $X.

### Что происходит при любых движениях рынка:
1. **Рынок летит вверх (Бычий импульс)**:
   * Сильная монета взлетает на **+18%**.
   * Слабая монета вяло поднимается на **+6%**.
   * Лонг зарабатывает +18%, шорт теряет -6%. **Итог: +12% чистой прибыли**.
2. **Рынок падает (Кровавый дамп / Пролив BTC)**:
   * Слабая монета валится на **-25%**.
   * Сильная монета сопротивляется и проседает всего на **-8%**.
   * Шорт зарабатывает +25%, лонг теряет -8%. **Итог: +17% чистой прибыли на падающем рынке!**
3. **Рынок стоит в боковике**:
   * Внутренний фундаментальный драйвер монеты-лидера медленно раздвигает спред в нашу пользу.

**Эмпирическая оговорка (аудит 2026-09-04).** Теория рыночной нейтральности предполагает коинтеграцию или хотя бы стабильный хедж-коэффициент между ногами. Независимое исследование за 18 месяцев показало, что **ни одна из четырёх пар не коинтегрирована** (Engle-Granger $p = 0,36$–$0,79$, ADF на остатках $p = 0,16$–$0,57$, half-life 35–62 дня, нестабильные hedge ratio). Лог-соотношения ведут себя как **случайное блуждание с дрейфом** (Hurst var-diff $0,49$–$0,57$); фильтр $\text{Ratio} > \text{EMA}_{10}$ **не даёт статистически значимого преимущества** на горизонтах 4h–24h для всех пар. Стратегия на практике — **направленная ставка на относительный дрейф (momentum)**, а не классический статистический арбитраж. Подробности: [`research/cointegration/RESULTS.md`](../research/cointegration/RESULTS.md).

Для трёх пар (ZEC/AVAX, ENA/SUI, SOL/ADA) при равном долларовом объёме ног net beta vs BTC близок к нулю ($\beta \in [-0,052; +0,100]$). **Исключение — BNB/ETH**: net beta **$-0,47$** (структурный шорт рынка), для beta-neutral sizing шорт ETH должен быть **$0,635\times$** от лонга BNB, а не 1:1.

## 2. Структура Корзины из 4 Фундаментальных Связок

Вместо хаотичной смены пар, алгоритм работает по **4 фундаментально обоснованным парам**, где лидер и аутсайдер отобраны на основе структурных денежных потоков криптоиндустрии:

```
┌────────────────────────────────────────────────────────────────────────┐
│               МУЛЬТИ-ПАРНАЯ КОРЗИНА (BASKET PORTFOLIO)                 │
├──────────────┬──────────────────┬──────────────────┬───────────────────┤
│ ПАРА         │ LONG (СИЛЬНЫЙ)   │ SHORT (СЛАБЫЙ)   │ ФУНДАМЕНТАЛЬНЫЙ   │
│              │                  │                  │ ДРАЙВЕР           │
├──────────────┼──────────────────┼──────────────────┼───────────────────┤
│ 1. ZEC/AVAX  │ Zcash (ZEC)      │ Avalanche (AVAX) │ ETF Grayscale vs  │
│              │                  │                  │ Мертвая L1        │
├──────────────┼──────────────────┼──────────────────┼───────────────────┤
│ 2. ENA/SUI   │ Ethena (ENA)     │ Sui (SUI)        │ Доходность USDe vs│
│              │                  │                  │ Дамп-разлоки VC   │
├──────────────┼──────────────────┼──────────────────┼───────────────────┤
│ 3. SOL/ADA   │ Solana (SOL)     │ Cardano (ADA)    │ Ончейн-объемы DEX │
│              │                  │                  │ vs Спящая сеть    │
├──────────────┼──────────────────┼──────────────────┼───────────────────┤
│ 4. BNB/ETH   │ BNB (BNB)        │ Ethereum (ETH)   │ Лаунчпулы Binance │
│              │                  │                  │ vs Отстающий ETH  │
└──────────────┴──────────────────┴──────────────────┴───────────────────┘
```

### Подробное обоснование каждой связки:
1. **ZEC / AVAX**:
   * **ZEC**: Катализатор институционального уровня — заявка Grayscale на конвертацию Zcash Trust в спотовый ETF на бирже NYSE Arca. Ограниченная эмиссия (халвинг) + взрывной спрос на приватность.
   * **AVAX**: Стагнирующий блокчейн старого цикла, нулевой приток институциональных фондов, затухание экосистемы.
   * *Примечание:* за 18 мес. ratio ZEC/AVAX вырос на **+8108%** — доминирующий драйвер in-sample PnL; см. раздел 5.
2. **ENA / SUI**:
   * **ENA**: Эмитент синтетического доллара USDe. В бычьей фазе ставки финансирования высоки, доходность протокола достигает 20–30% годовых, что вызывает бешеный спрос на токен ENA.
   * **SUI**: Регулярные ежемесячные разлоки сотен миллионов токенов для ранних венчурных инвесторов, создающие перманентное давление продаж в биржевой стакан.
3. **SOL / ADA**:
   * **SOL**: Абсолютный лидер ончейн-ликвидности, розничного объема торгов и комиссий на децентрализованных биржах (DEX).
   * **ADA**: Старейший блокчейн с крайне низкой реальной экономической активностью и оттоком разработчиков.
4. **BNB / ETH** (требует пересмотра sizing или исключения):
   * **BNB**: Регулярные сжигания монет + постоянные лаунчпулы Binance с доходностью в новых токенах.
   * **ETH**: Хроническое отставание по темпам роста от других активов первого эшелона в текущем цикле.
   * *Примечание:* net beta **$-0,47$** vs BTC; в честном бэктесте Scenario C эта пара **net negative** (см. раздел 4).

## 3. Алгоритм исполнения сделок (Execution Rules)

### 3.1. Разделение капитала и плечо
* Депозит пользователя делится на **4 равных слота** (по 25% баланса на каждую пару).
* При балансе **$20,000**: на каждый слот выделяется **$5,000 маржи**.
* Рабочее эффективное плечо на слот: **7x** (настраивается в пределах 5x–7x).
* Объем открываемой позиции на слот: `$5,000 × 7 = $35,000` total:
  * **$17,500 в LONG** монеты-лидера.
  * **$17,500 в SHORT** монеты-аутсайдера.

### 3.2. Правило входа в сделку (Trend Entry)
* **Таймфрейм анализа**: 4 часа (4h) с поминутным мониторингом на 1h/15m.
* **Индикатор**: Экспоненциальная скользящая средняя **EMA 10** от соотношения `Price(CoinA) / Price(CoinB)`.
* **Условие входа**:
  $$\text{Ratio}_{\text{Close}} > \text{EMA}_{10}(\text{Ratio})$$
* Если пара находится выше EMA 10 и слот свободен — робот немедленно выставляет два одновременных рыночных ордера (Market Buy + Market Sell).
* Если соотношение ниже EMA 10 — слот **находится в 100% USDT кэше** (вход запрещен).

### 3.3. Правила выхода из сделки (Exit Triggers)
Сделка закрывается по первому наступившему событию (порядок проверки зависит от конфигурации воркера):

1. **Тейк-профит (Take-Profit)** — если не отключён (`TP_DISABLED=false`, значение по умолчанию):
   * Порог **+5,0%** интерпретируется от **выделенной маржи слота** при `RISK_MODE=margin` (режим по умолчанию в коде).
   * При плече **7x** это эквивалентно движению ratio примерно на **+0,71%** ($+5\% / 7$) от точки входа по обеим ногам.
2. **Стоп-лосс (Stop-Loss)**:
   * Порог **$-1,5%$** от **выделенной маржи слота** при `RISK_MODE=margin`.
   * При плече **7x** это **$-0,21%$** adverse move ratio ($1,5\% / 7$) — порядка **1,6 минутной сигмы** шума; SL срабатывает от микроструктурного шума, а не от «структурного» разворота спреда.
   * **Убыток по слоту при срабатывании SL = 1,5% от маржи слота** (≈0,375% от общего депозита при 25% на пару), **до** комиссий и проскальзывания; net-убыток выше.
3. **Выход по смене тренда (Trend Flip Exit)**:
   * Если 4-часовая свеча соотношения закрылась ниже $\text{EMA}_{10}$:
     $$\text{Ratio}_{\text{Close}} < \text{EMA}_{10}(\text{Ratio})$$
   * Позиция закрывается с текущим результатом, освобождая слот.

**Альтернативные режимы риска (см. [`doc/04_WORKER_ENGINE_SPECIFICATION.md`](04_WORKER_ENGINE_SPECIFICATION.md), раздел 7):**
* **`RISK_MODE=spread`**: TP/SL задаются как **% движения ratio**, затем пересчитываются в PnL% маржи через эффективное плечо (`total_position_volume_usd / allocated_margin_usd`).
* **`SL_ATR_MULT > 0`**: динамический SL = $1,5 \times \text{ATR}_{14}$ (4h ratio, Wilder), с потолком `SL_MAX_MARGIN_PCT` (по умолчанию 10% маржи). При trend-flip exit ATR-SL часто не успевает сработать.
* **`TP_DISABLED=true`**: фиксированный TP отключён; выход только по SL, trend flip или panic close — рекомендуется для paper-trading (Scenario C).

### 3.4. Реинвестирование (Compounding)
После закрытия любой сделки прибыль мгновенно падает на свободный баланс. Объем следующего ордера рассчитывается от **нового увеличенного баланса** ($bal \times 7 / 4$). Это запускает формулу сложного процента.

**Scenario A** — текущая live-логика: плечо **7x**, TP **+5%** / SL **$-1,5%$** от маржи (`RISK_MODE=margin`), вход на live ticks каждую 1m при `Ratio > EMA10`, без cooldown, pessimistic intrabar (SL first).

**Scenario C** — предлагаемая ре-параметризация: плечо **3x**, вход **только на закрытии 4h** выше EMA10, выход **trend flip** (4h close ниже EMA10), SL **$1,5 \times \text{ATR}_{14}$** с cap **10%** маржи, cooldown/re-entry guard, слот **25%** equity, **без фиксированного TP**.

## 5. Робастность и ограничения

### 5.1. Конвенции касания барьеров (Scenario A)

| Конвенция | A + costs | A0 zero cost |
| :--- | :---: | :---: |
| Pessimistic (SL first) | **$-100%$** | **$-100%$** |
| TP-first | **$-100%$** | $-99,98%$ |
| Close-only | **$-100%$** | +3011,94% (нерелевантно без costs) |

**Bracket net profit Scenario A:** **[$-100%$, $-100%$]** — ликвидация не артефакт модели intrabar.

### 5.2. Концентрация ZEC/AVAX

81,7% taker-прибыли Scenario C приходится на ZEC/AVAX, чей ratio за 18 мес. вырос **+8108%** (sample-specific drift). Стратегия без этой пары на taker почти не зарабатывает (+2,76% / 6 мес.).

### 5.3. Out-of-sample (2025-09-01 — 2026-02-28)

| Вариант | Net profit | Max DD | Trades | Daily Sharpe |
| :--- | :---: | :---: | :---: | :---: |
| C taker (in-sample) | +48,63% | 16,17% | 401 | 1,66 |
| **C taker (OOS)** | **+22,07%** | **53,10%** | 378 | 0,89 |
| C maker (in-sample) | +116,74% | 9,74% | 401 | 2,95 |
| **C maker (OOS)** | **+72,97%** | **42,56%** | 378 | 1,73 |

Направление edge подтверждено OOS, но **просадка выросла с 16% до 53%** (taker) — whipsaw в боковике late 2025.

### 5.4. Прочие ограничения

* **SL не протестирован:** в 401 сделке Scenario C SL сработал **1 раз** — tail protection фактически не проверена.
* **BNB/ETH net negative** in-sample и **net beta $-0,47$** — не market-neutral; рекомендуется beta-weight (short 0,635×) или исключение пары.
* **EMA20 in-sample:** +80,04% vs +48,63% при EMA10 — **in-sample selection**, OOS не валидировано.
* **ATR multiplier invariant:** при trend-flip exit первым результаты идентичны для SL ATR mult 1,0–3,0.
* **Dashboard leak:** gross PnL без fees/slippage завышает результат; live-метрики должны быть **NET** (`entry_fees_usd`, `exit_fees_usd`, `gross_pnl_usd` → net equity).

### 5.5. Отзыв «стресс-теста» из старого раздела 5

Описание сценария о проливе ZEC 29.05–05.06.2026 (стратегия «не потеряла деньги», рост баланса за неделю краха) **не подтверждено** честным 1m-бэктестом Scenario A и **не должно** использоваться в маркетинге.

## 6. Рекомендуемая конфигурация для paper-trading / дальнейшей валидации

Параметры задаются через env (полный справочник: [`doc/04_WORKER_ENGINE_SPECIFICATION.md`](04_WORKER_ENGINE_SPECIFICATION.md), раздел 7). **Значения по умолчанию в коде сохраняют legacy-поведение (7x, TP +5%, SL $-1,5%$ margin)** — для paper-trading их нужно **переопределить явно**:

| Переменная | Рекомендуемое значение | Назначение |
| :--- | :--- | :--- |
| `DEFAULT_LEVERAGE` | `3` | Снижение microstructure churn (default в коде: `7`) |
| `RISK_MODE` | `spread` | TP/SL как % движения ratio → PnL% маржи |
| `SL_ATR_MULT` | `1.5` | Динамический SL от ATR14 4h ratio |
| `SL_MAX_MARGIN_PCT` | `10` | Потолок SL в % маржи |
| `TP_DISABLED` | `true` | Без фиксированного TP; выход по trend flip |
| `REENTRY_GUARD_ENABLED` | `true` | Cooldown после SL, hysteresis, streak block |
| `ENTRY_EXECUTION_MODE` | `maker_hedge` | После проверки на малом счёте (default: `market`) |
| `EXIT_EXECUTION_MODE` | `maker_hedge` | Для trend-flip (TP/panic/SL остаются market) |
| `ENTRY_ON_4H_CLOSE_ONLY` | `true` | Event-driven входы строго по закрытию 4h-свечи; default: `false` |

Режим `ENTRY_ON_4H_CLOSE_ONLY=true` теперь реализован в воркере: входы разрешены только на первом скане после нового закрытия 4h-свечи и при условии `closedRatio > EMA10`, что соответствует условиям валидированного бэктеста Scenario C.
