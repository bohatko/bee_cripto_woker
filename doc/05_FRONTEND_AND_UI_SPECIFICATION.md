## 1. Концепция дизайна и UI-система

Интерфейс платформы проектируется по современным канонам **Web3 / Neo-Fintech**:
* **Цветовая палитра**: Глубокая темная тема (`#0B0E14`, `#111622`, `#1A2234`) с неоновыми акцентами:
  * **Brand Primary**: Янтарно-золотой / Медовый неоновый (`#F59E0B`, `#FBBF24`) — символизирует рабочую пчелу (Bee Worker) и золото.
  * **Success / Profit**: Изумрудный зеленый (`#10B981`, `#059669`).
  * **Danger / Stop / Loss**: Рубиновый красный (`#EF4444`, `#DC2626`).
  * **Muted / Text**: Серебристо-серый (`#94A3B8`, `#CBD5E1`).
* **Типографика**: Чистые шрифты `Inter` или `Geist Sans` для текста, моноширинный `Geist Mono` или `JetBrains Mono` для цен, объемов и PnL.
* **Компоненты**: `shadcn/ui` на базе Tailwind CSS, Radix UI Dialogs, Tooltips, Tabs, Dropdowns.

## 3. Детальная спецификация экранов

### 3.1. Главный Лендинг (`/`) — реализовано (2026-09-15)

**Бренд:** `Crypto B` (от «крипто пчела»). Слоган: EN *"While you sleep, the bee works for you."* / RU «Пока вы спите, пчёлка работает за вас.»

1. **Header**:
   * Логотип: пчела в янтарной плашке + вордмарк `CRYPTO B` + тег `WORKER`.
   * Навигация (якоря): «Продукты», «Как это работает», «Калькулятор комиссии», «Тарифы», «Безопасность», «FAQ».
   * Кнопки: «Войти» (ghost), «7 дней бесплатно» (amber), переключатель языка EN/RU.
2. **Hero-секция с интерактивной пчелой** (`web/src/components/landing/BeeHeroScene.tsx` + `bee-scene.ts`):
   * Three.js point-cloud пчела (~17,5 тыс. частиц: тело с медовыми полосами, голова, глаза, усики, жало, два машущих крыла) + фоновая «дымка».
   * Курсор работает «факелом»: точки рядом с указателем подсвечиваются и увеличиваются (кастомный ShaderMaterial, `uPointer` / `uPointerStrength`).
   * Пчела излучает монеты-тикеры (BTC, ETH, XRP, SOL, BNB, USDT) через Sprite-пул; клик по hero даёт залп монет (`uBurst`).
   * Parallax-наклон пчелы и камеры за курсором, idle-покачивание, взмах крыльев.
   * Оптимизация: `three` грузится динамическим import (отдельный чанк, вне First Load JS), пауза рендера вне viewport и при скрытой вкладке, cap pixel ratio 1.75, `prefers-reduced-motion` → статичный кадр, отсутствие WebGL → CSS-фолбэк с эмодзи-пчелой и тикер-чипами.
   * Живая плашка статуса: *"N из M пар корзины выше EMA10"* (Realtime `pair_market_data`).
3. **Live-риббон сканера**: карточки пар из `pair_market_data` (`current_ratio`, `ema_10`, `is_in_trend`) через Supabase Realtime.
4. **Продукты** — только фактическое описание того, что уже работает, без маркетинговых обещаний доходности:
   * «Корзина парного трейдинга»: `strategy_pairs` + momentum-скринер, вход по закрытой 4h-свече выше EMA10, слот 20% свободной маржи, плечо ≤3x, выходы ATR-SL / trend flip / panic close.
   * «Dip-Buy сигналы»: BTC / ETH / XRP, минутные свечи, изолированное плечо, биржевые reduce-only TP/SL, шкала готовности 0–100%, Telegram-алерты 80%/90%, репликация на аккаунт.
5. **«Как это работает»**: 4 шага (подключение биржи → включение движков → зеркалирование ордеров на Railway → live-мониторинг) + чипы фактических поверхностей платформы (дашборд, сигналы, история, биллинг, админка, Telegram).
6. **Калькулятор комиссии** (заменяет прежний ROI-калькулятор): ползунок «новая чистая прибыль выше HWM» → вывод фиксированной платы $20, доли 10% и итога за неделю + эффективной ставки. Никаких прогнозов доходности.
7. **Тарифы**: $20/нед + 10% High-Water Mark, 7 дней бесплатно, список из 6 фактических фич.
8. **Безопасность API**: 3 блока — запрет вывода, whitelist статического IP `54.198.120.45`, шифрование AES-256-GCM.
9. **FAQ** (нативный `<details>`): кастодия средств, поддерживаемые биржи, поведение при неоплате, плечо/риск корзины, ручное управление позицией. Ниже — блок «Раскрытие рисков» и футер.

> **Важно:** все прежние цифры доходности ($1,367,000 / 8.7% DD / 62.3% winrate) удалены с лендинга согласно аудиту (см. [`doc/02_STRATEGY_AND_BACKTESTS.md`](02_STRATEGY_AND_BACKTESTS.md) §4.0). Лендинг не показывает историческую доходность и не описывает стратегию как гарантированно прибыльную.

### 3.2. Главный Дашборд пользователя (`/dashboard`)
* **Виджет баланса**:
  * Общий баланс (Total Equity) в USDT.
  * Свободная маржа (Available Margin).
  * Дневной / Недельный PnL (+X.XX% / +$YYY).
* **Монитор здоровья системы (System Health Bar)**:
  * Три индикатора с зелеными/желтыми статусами:
    1. `Торговое ядро: В сети (12ms)`
    2. `Биржа (OKX): Подключено`
    3. `Статус бота: Активен (Корзина 4 пар)`
* **Кнопки управления (с обязательными модалками подтверждения)**:
  * Кнопка `Старт / Пауза`: включает или приостанавливает работу робота.
  * Кнопка `Panic Close All`: экстренный сброс всех позиций по рынку.
* **Таблица активных парных позиций**:
  * Столбцы: 
    * Пара (`ZEC/AVAX`, `ENA/SUI`...).
    * Время в сделке (чч:мм).
    * Нога LONG (цена входа / текущая / PnL).
    * Нога SHORT (цена входа / текущая / PnL).
    * **Суммарный PnL связки ($ и %)** с цветовой шкалой прогресса до TP (+5.0%) и SL (-1.5%).
* **Уведомления Supabase Realtime**:
  * Всплывающие toast-уведомления при закрытии сделок: *«Связка ZEC/AVAX успешно закрыта по Take-Profit: +$145.20 (+5.1%)»*.

### 3.4. Экран Биллинга и Инвойсов (`/billing`)
* **Статус подписки**:
  * Бейдж: `Пробный период (осталось 4 дня)` или `Подписка активна (до 10 сентября)`.
* **Текущий активный инвойс**:
  * Номер инвойса: `INV-2026-09-001`.
  * Таймер обратного отсчета: `До заморозки осталось: 38ч 14м`.
  * Сумма: **$20.00** (фикс) + **$45.20** (10% от $452 чистой прибыли) = **$65.20 USDT**.
* **Модальное окно оплаты (QR-код)**:
  1. Выбор сети: `USDT TRC-20` или `USDT BEP-20`.
  2. Генерация большого четкого **QR-кода** адреса биржи сервиса.
  3. Текстовое поле с адресом кошелька и кнопкой копирования в один клик.
  4. Поле для ввода: `TxID (Хеш транзакции)`.
  5. Кнопка «Подтвердить отправку перевода».
  6. После отправки статус инвойса меняется на `На проверке у администратора`.

## 5. Панель Администратора (`/admin`)

### 5.1. Инвойсы
* Таблица всех выставленных инвойсов пользователей:
  * ID пользователя и Email.
  * Период и чистая прибыль по HWM.
  * Сумма инвойса ($).
  * Указанный пользователем TxID с прямой кликабельной ссылкой на Tronscan / BscScan.
  * Кнопки действий:
    * 🟢 **Подтвердить (Approve)**: продлевает подписку пользователя на 7 дней в базе Supabase, снимает заморозку, отправляет email.
    * 🔴 **Отклонить (Reject)**: возвращает инвойс в статус неоплаченного с указанием причины (неверный хеш, сумма меньше необходимой).

### 5.2. Pairs & Rotation (added 2026-09-07)
Вкладка **Pairs** на `/admin` (Realtime на `strategy_pairs` и `pair_selection_runs`):

1. **Current Active Basket** — до 4 активных пар: score, metrics (t-stat / corr / β-diff / funding), `activated_at`.
2. **Auto-Rotation** toggle → `ConfirmModal` → UPDATE `engine_settings.auto_rotation_enabled` + `audit_logs`.
3. **Run pair selection now** → `ConfirmModal` → INSERT `pair_selection_runs` (`trigger_source='admin'`, `status='pending'`) + audit; статус прогона обновляется live (pending → running → completed/failed).
4. **Run history** — последние N прогонов с expandable candidates/replacements JSON.

Фильтры пар на `/history` и `/history/bot` строятся динамически из фактических `pair_symbol` в данных (плюс активная корзина), без хардкода четырёх тикеров.
Дашборд `TradeReadinessMonitor` читает пары из `pair_market_data` (пишет воркер по union-скану).
